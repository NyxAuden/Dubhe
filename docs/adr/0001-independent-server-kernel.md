# 独立服务端内核，不编排现有内核进程

用户希望不再为了不同协议安装不同内核，因此本项目独立实现协议处理与运行机制，而不是包装或启动 Xray、sing-box、Nowhere。范围限于服务端：现有 Clash、sing-box、V2Ray 系客户端及 Anywhere 通过其支持的协议接入；不开发终端用户客户端或运营平台。

核心使用 Rust，允许必要的非 Rust 依赖。新协议通过扩展内核并重新构建发布，不要求运行时加载第三方插件。相较于包装现成内核，这会增加初期实现与互操作验证成本，但保留统一生命周期、资源管理与能力扩展的目标。

此决策来自用户已明确的产品边界；不代表具体许可证、Rust 库选型、配置格式或首批平台已获用户单独确认。
