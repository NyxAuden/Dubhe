# 上线就绪性审核（2026-11-28）

审核对象：`b054c47`，版本 0.1.0（development version）。
审核方式：本地只读核对源码、工作流、部署材料与互通归档；**不是**对全部源码、
传递依赖或法域合规的独立审计。

## 一句话结论

**可以做隔离内测，不能直接承载唯一生产出口。**
最关键的一件事：把实际交付的 ELF 放进拟部署的单租户边界，用真实客户端证明
「允许的能通、禁止的出不去、失败后能恢复」。

## 互通证据的证据层级

**不能把一个协议族某一行通过推广给同族所有承载。**

| 层级 | 事实 |
|---|---|
| x86_64 / Xray v26.10.31 | 通过：Trojan、VMess、8 个 SS 单密钥/EIH 用例、VLESS 基础/XUDP/Vision/Encryption/REALITY/WS/gRPC/HTTPUpgrade/XHTTP 等列明组合 |
| x86_64 / sing-box v1.14.4 | 通过：Trojan、VMess、SS、AnyTLS、Hysteria2、TUIC、ShadowTLS、Snell v4、VLESS 相应组合。**Naive 在 `valid` 阶段客户端提前退出**，不能列为通过 |
| x86_64 / mihomo v1.19.33 | 实际通过 8 项：5 个 SS 单密钥、Snell v4、VLESS HTTP、VLESS Vision。原轮 15 项失败仍为 3 正向 / 7 负向 / 5 阶段未判明 |
| 其他平台或专项记录 | gRPC、XHTTP、REALITY、Snell v5/v6、Naive H2/H3、WireGuard、NW3 有指定组合记录；**不能算作当前 x86 发布包通过** |
| 本地实现/证据不足 | SOCKS5、HTTP/Mixed 有协议级测试；Dokodemo 回环不能证明透明代理部署；未逐项列证的承载不继承 VLESS 结果 |

发布用词固定三档：**已验证（列出组合与平台）** / **实验性已实现（不承诺互通）** /
**明确不支持**。

## 两条实质安全问题

### 1. NW3 绕过统一出口策略

NW3 不是接入内核转发链的入站，而是把 Nowhere 的 Portal 作为独立子系统嵌入同一进程：
自行绑定端口、**自行出站**（`out=direct` 时由 Nowhere 的 `OutboundDialer` 直接连接）、
独立日志、独立 `NOW_*` 环境变量。

**三者都不经过本内核的 `outbounds`、`route`、`reject`、DNS 策略，也不计入流量统计
与连接限额。** 详见 `docs/nw3.md`。

→ 首轮单租户灰度应**禁用 NW3 Portal/Egress**，以及在进程外验证默认拒绝。

### 2. `unsafe` 的实际风险面比关键词计数小

- `src/lib.rs` 的 `GlobalAlloc` 计数包装受 `#[cfg(test)]` 控制，release 不含。
- Snell 与配置中的多数命中是字符串/注释/测试里的 `"unsafe-raw"`，不是 `unsafe` 块。
- 真正值得 release 专项审查的是 `src/udp/shadowsocks.rs` 的 `&mut [u8]` → socket2
  接收缓冲转换；已有 `SAFETY` 注释与截断检查。**是审查点，不是已发现漏洞。**

## 只能再做五件事（按顺序放行受控试用）

1. **冻结首发边界，修正分发许可。** 只选 Linux x86_64-musl、单租户、一个已通过的
   客户端/协议组合和明确出站策略；列出关闭的入口、已知失败、回滚目标。
   *完成标志*：部署者能从一页说明判断自己的场景是否在范围内。
2. **验用户真正拿到的包。** 演练发布工作流，解包核对包与 ELF 双哈希、架构、静态性、
   示例配置；在 Debian 11 非 root 对该 ELF 做 7/7。
   *完成标志*：从下载资产能追溯到实测日志。
3. **在部署形态中验证安全边界和真实业务。** 实际客户端跑允许转发、错误凭据拒绝、
   禁止目标未收到连接；核查管理面仅回环、进程外默认拒绝。
   *完成标志*：既有成功路径，也有目标侧与进程外的拒绝证据。
4. **同一 ELF 做两小时低负载 soak。** 持续连接 + 反复短连接，周期排空，记录同一 PID
   的 RSS、FD、活动流、错误与累计业务字节。
   *完成标志*：载荷正确、无意外重启、排空后资源回基线或有可解释的平台值。
5. **做一次单机故障与回切演练。** 从压缩包部署，演练坏配置拒绝、证书/token 轮换、
   停机排空、恢复上一版二进制与配置。
   *完成标志*：换一个操作者按手册能识别故障、恢复服务并证明恢复成功。

## 必须明确排除的承诺

- 公网多租户
- 无人值守生产 SLA
- 把 NW3 纳入统一出口策略
- 把内存计数当持久计费
- 对既有连接即时撤权
- 全协议 / 全客户端 / 全出站等价
- 未验平台
- 以回环 Gbit/s 推算线上容量

16 项互通失败应写「**失败、根因未定位、调查暂停**」，不能写成「已知均不支持」，
也不能算通过。

`0.1.0` 作为首次公开试用版本合理，发布说明应显式标「开发版/预发布」，不要让版本号
承担成熟度承诺。
